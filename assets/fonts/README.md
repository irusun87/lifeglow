# 페이퍼로지 (Paperlogy) 1.001

라이프글로우 제목·자막용 폰트. 무료 상업 이용 가능한 SIL Open Font License 1.1 폰트라 저장소에 함께 둔다.
제목·자막에 쓰는 굵기만 넣었다 (전체 9종은 프로젝트 공유 폴더 `assets/fonts/paperlogy/`).

| 파일 | 용도 |
|---|---|
| `Paperlogy-8ExtraBold.ttf` | 상단 2줄 제목 (기본) |
| `Paperlogy-9Black.ttf` | 제목 강조 키워드를 더 두껍게 할 때 |
| `Paperlogy-7Bold.ttf` | 자막 (흰 글씨 + 검은 외곽선) |
| `Paperlogy-6SemiBold.ttf` | 이름/나이 라벨 같은 보조 그래픽 |
